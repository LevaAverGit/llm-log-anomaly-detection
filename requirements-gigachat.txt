# Optional: the GigaChat (Sber) cloud provider for the cross-model comparison.
#
# The core install (requirements.txt) stays light and fully offline-reproducible.
# Install this only if you want to include GigaChat in `make run-models`:
#
#     .venv/bin/pip install -r requirements-gigachat.txt
#     export GIGACHAT_CREDENTIALS="<your Sber GigaChat authorization key>"
#
# Without the package or the GIGACHAT_CREDENTIALS environment variable the
# GigaChat model is skipped and reported as unavailable — never faked.
# Pinned <0.4: the 0.3.x line targets langchain-core 0.3.x, matching the core
# stack in requirements.txt (langchain 0.3.x). 0.4+ pulls langchain-core 1.x,
# which conflicts with that stack.
langchain-gigachat>=0.3,<0.4
